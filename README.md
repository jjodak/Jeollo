# 절로 Jeollo

> AI 이미지 인식으로 보고, 듣고, 모으는 사찰 문화유산 큐레이션 서비스

절로는 사찰을 단순히 둘러보는 공간이 아니라, 걸음마다 전시가 되는
`지붕 없는 박물관`으로 경험하게 만드는 모바일 서비스 기획 프로젝트입니다.
사용자가 사찰의 문화유산을 카메라로 스캔하면 AI가 대상을 인식하고,
음성/영상 도슨트와 상세 해설, 디지털 스탬프 수집 경험을 제공합니다.

## 문제 정의

불교문화와 전통문화에 대한 2030세대의 관심은 커지고 있지만, 실제 사찰
방문은 문화유산 향유 경험으로 충분히 이어지지 못하고 있습니다.

자체 설문조사 기준, 2030세대 사용자는 사찰 방문 시 다음과 같은 불편을
느꼈습니다.

- 교통편이 좋지 않음
- 무엇을 봐야 할지 모르겠음
- 관련 정보를 찾기 어려움
- 놀거리와 구경거리가 부족함
- 편의시설이 부족함

절로는 이 중 콘텐츠 접근성 문제에 집중합니다. 사찰 안의 건축, 단청,
불상, 탱화, 공예, 의례와 같은 유무형 문화유산을 현장에서 바로 이해하고
수집할 수 있는 참여형 경험으로 전환합니다.

## 핵심 가치

- **발견**: 현재 위치를 기반으로 주변 사찰과 방문 가능한 콘텐츠를 추천합니다.
- **이해**: 문화유산을 카메라로 스캔하면 도슨트 해설을 제공합니다.
- **수집**: 스캔과 청취 경험을 디지털 스탬프로 기록합니다.
- **재방문**: 관심 사찰의 소식, 행사, 프로그램을 구독하고 다시 방문하도록 연결합니다.

## 주요 기능

### 홈

- 위치 기반 사찰 추천
- 금주의 인기 소식 제공
- 추천 블로그 자동 연결
- 사찰 행사 및 템플스테이 정보 노출
- 도슨트 투어 핵심 기능으로 바로 이동

### 스캔

- 문화유산 카메라 스캔
- AI 이미지 인식 기반 문화유산 확인
- 음성/영상 도슨트 재생
- 다른 화면으로 이동해도 하단 PIP 형태로 도슨트 계속 재생
- 도슨트 스크립트 보기
- 문화유산 상세 정보 확인

### 탐색/검색

- 상단 검색을 통한 사찰 및 문화유산 검색
- 문화유산, 사찰, 템플스테이/행사, 테마 투어 카테고리 탐색
- 각 카테고리별 목록 및 상세 정보 제공
- 지도 기반 사찰 위치 표시
- 스탬프 획득 사찰 위치 표시

### 스탬프 도감

- 방문 및 스캔으로 획득한 디지털 스탬프 목록화
- 사찰별 문화유산 발견 현황 표시
- 아직 발견하지 못한 문화유산을 비공개 카드로 보여주어 추가 탐색 유도

## 서비스 흐름

1. 사용자는 홈에서 현재 위치 주변의 사찰과 행사 정보를 확인합니다.
2. 방문한 사찰에서 문화유산을 카메라로 스캔합니다.
3. AI가 문화유산을 인식하고 도슨트 콘텐츠를 재생합니다.
4. 사용자는 스크립트와 상세 정보를 함께 확인합니다.
5. 감상한 문화유산은 디지털 스탬프로 수집됩니다.
6. 사용자는 탐색 화면과 지도에서 다른 사찰, 행사, 테마 투어를 이어서 발견합니다.

## 차별점

기존의 사찰 정보 서비스가 검색과 안내에 머무른다면, 절로는 현장 감상,
도슨트 해설, 수집형 경험을 하나의 흐름으로 연결합니다.

- 사찰의 유형유산과 무형유산을 함께 다루는 현장형 큐레이션
- 이미지 인식 기반의 즉시 해설 경험
- 스탬프 수집을 통한 게임화된 탐방 동기
- 관심 사찰 구독을 통한 행사 참여 및 재방문 유도
- 전통문화포털, 국가유산청 등 기존 아카이브와 연계 가능한 콘텐츠 구조

## 비즈니스 모델

절로는 2030세대 비종교인 및 불교문화 관심층을 B2C 사용자로, 협력 사찰과
문화유산 현장을 B2B 파트너로 연결하는 양면 플랫폼을 지향합니다.

- B2C: 도슨트, 추천 콘텐츠, 스탬프 수집, 사찰 소식 구독
- B2B: 협력 사찰의 행사 및 체험 프로그램 홍보
- 수익원: 광고 노출, 알림/홍보 계약, 유료 도슨트 또는 제휴 콘텐츠 확장
- 초기 목표: 가입자 3만 명
- 유효 시장: 2030세대 불교문화 관심층 30~40만 명
- 전체 잠재 시장: 국내 불교문화 관심층 80~90만 명

## 기대 효과

- 사찰 방문자가 문화유산을 더 깊이 이해하도록 돕는 상시 도슨트 경험 제공
- 지역 사찰의 고유 콘텐츠와 행사 정보를 균형 있게 확산
- 전통공예 작가 및 지역 문화 종사자와의 협업 구조 확장
- 협력 사찰 20~25개소 대상 행사/프로그램 홍보 계약 기반 B2B 수익 창출

## 프로토타입 실행

React와 Vite로 `홈`, `스캔`, `검색` 3개 하단탭을 우선 구현한 모바일 웹
프로토타입을 구성했습니다. 별도 목업 프레임 없이 브라우저 화면 전체가 앱처럼
동작하며, 각 탭 화면 코드는 유지보수를 위해 별도 폴더로 분리했습니다.

```text
src/pages/home
src/pages/scan
src/pages/search
```

```bash
npm install
npm run dev
```

개발 서버 실행 후 브라우저에서 안내되는 로컬 주소로 접속하면 됩니다.
